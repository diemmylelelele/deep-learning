# Deep Learning

This repository contains exercises and projects completed during the Deep Learning and Advanced Deep Learning courses. It serves as a comprehensive collection of practical implementations using Python and Jupyter Notebooks, showcasing a variety of deep learning models and techniques.

### Supervised Learning

- Convolutional Neural Networks (CNNs): Various Convolutional Neural Networks for image classification.

- Transfer Learning: Leveraging pre-trained models for different tasks.

- VGG16: Implementation of the VGG16 deep learning model for image classification.

### Sequence Models

- Recurrent Neural Networks (RNNs): Used for sequential data like text or time series.

- BERT: Fine-tuned BERT for sentiment classification on the IMDB dataset.

- PhoBERT: Fine-tuned PhoBERT for Vietnamese sentiment analysis on the ecommerce_review dataset.

### Generative Models

- Generative Adversarial Networks (GANs): Implementation of GANs for image generation.

### Reinforcement Learning

- Q-Learning & Deep Q-Learning: Trained agents to solve environments like FrozenLake and CliffWalking using traditional and deep reinforcement learning methods.

### Graph-Based Models
- Graph Neural Networks (GNNs): Developed DNN and GNN models for edge classification on the Cora citation dataset.
