# Deep Learning

This repository includes all exercises and projects completed during the Deep Learning and Advanced Deep Learning courses. It serves as a collection of practical implementations covering various deep learning models and techniques using Python and Jupyter Notebooks.

### Implemented Models & Techniques
- CNN Architectures: Various Convolutional Neural Networks for image classification.

- Generative Adversarial Networks (GANs): Implementation of GANs for image generation.

- Recurrent Neural Networks (RNNs): Used for sequential data like text or time series.

- Transfer Learning: Leveraging pre-trained models for different tasks.

- VGG16: Implementation of the VGG16 deep learning model for image classification.
